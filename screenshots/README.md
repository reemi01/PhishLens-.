# PhishLens 🔐

A Python-based phishing detection and SOC triage tool.

## Features
- Rule-based phishing risk assessment
- Suspicious URL analysis
- Low, Medium, and High risk classification
- Optional VirusTotal integration
- Incident logging and JSON reports
- CSV export and SOC dashboard

## Technologies
- Python
- Streamlit
- Requests
- VirusTotal API
